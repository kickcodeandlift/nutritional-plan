GER scale how hard each set is

G74-6 reps in reserve. Feeder sets.
G82-3 reps in reserve.
G91 rep in reserve.
G10Stop when the next rep can't be done with perfect form. No forced reps.
G11Fail after losing perfect form.
G12Use help and techniques to go beyond failure.
G13No description in the program. Tagged on the Week 5 widowmaker.

1x8-12 G10 = 1 working set, 8-12 reps, finishing at G10. MR = muscle round, taken to G11. BO = backoff set. Warm-up and feeders come before and are not counted.

  • Your plan
    D1 Mon
    D2 Wed
    D3 Fri
    D4 Sat
    Weeks 7-8 days to be decided
  • Limits
    Do not exceed the prescribed sets
    Do not go past the prescribed failure
  • Warm-up
    2 sets x 15-20 reps before the first exercise of each muscle
  • Feeders
    2-3 sets x 4-8 reps at 70-80% of the intended load, G7
    Before the 1st and 2nd exercise of each muscle
    1 feeder set before the other exercises of that muscle
  • MR (muscle round)
    The program only writes "muscle round" with GER 11 (calves: no GER)
    GER 11 = failure after losing perfect form
    Sets, reps and rest are not stated in the program
    Confirm the number of sets with your coach
  • BO (backoff)
    Cut 20-30% of the top set load
    1 set to failure, 10-15 reps, G10
  • DC rest-pause
    Load for 8 reps
    Go to failure, pause 20s
    Max reps, pause 20s
    Failure again
    When block 1 reaches 10-11 reps, raise the load
  • Widowmaker
    Load for failure at 10-12 reps
    Keep going to 15-20 reps
    Rest as needed between reps, do not rack
  • GER on these methods
    The program intro lists rest-pause G11 and widowmaker G12
    The Week 5 day pages tag them G12 and G13
    Where a day page shows a GER, it is shown here
  • Training partner
    Max 1 forced rep per set, including rest-pauses
  • Rest between sets
    Not specified in the program
  • DC stretch after each muscle
    60-120s under load
    Biceps, triceps, lats hang, chest DB, shoulders on cable, hams with bar or DB and straight spine, quads sissy position
    If you hold over 120s, add load

⚙ Settings: gyms, backup, GitHub sync

Gyms

Pick the gym at the top before you log. Tap + at the top to add another gym (up to 6). Remove deletes that gym's logs and notes, so make a Backup first. Each gym keeps its own weights, charts and ranking, so a machine at one gym never mixes with another.

Backup

Your log lives only on this phone, in this app or browser. Removing the Home Screen icon, clearing site data or switching browser deletes it. Tap Backup after each session and send it to Notes, Mail or WhatsApp. Restore puts it back.

GitHub sync

Saves your log to a private GitHub repo automatically, so it survives deleting the app. Setup once: 1) create a private repo, 2) create a fine-grained token limited to that repo with Contents read and write, 3) enter both below. The token stays on this device only.
